# Sistema Inteligente de Monitoramento de Ruído Urbano com IoT

Projeto desenvolvido para a disciplina de Internet das Coisas.

## Integrantes

* Adam
* Jasmin
* Emanuel Alves

## Descrição

O projeto consiste em um sistema de monitoramento de ruído utilizando ESP32, sensor de som e protocolo MQTT. Quando o nível de ruído ultrapassa um limite pré-definido, um buzzer é acionado para emitir um alerta sonoro.

## Tecnologias Utilizadas

* ESP32
* MQTT
* Wokwi
* Arduino IDE
* HiveMQ Broker
